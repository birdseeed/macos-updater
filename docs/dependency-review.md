# Dependency review

## Scope

This static triage was recorded on **1 November 2026** from source manifests, advisory records and bounded source searches. It covers 270 inventory records, 115 unique advisory records and 77 alias-collapsed groups. Alias grouping is not a count of exploitable defects. Sixteen matching package/version rows reduce to 15 distinct package names after PyJWT case normalisation. Eighteen inventory entries were unpinned; some other entries have hash-locked constraints. The full structured record is [dependency-review.json](dependency-review.json).

This is not an installed dependency inventory, complete transitive graph, exploit test or product certification. It did not inspect live configuration, deployment images or toolchains. Package advisories apply only where their affected code and conditions are present. Do not read a conditional library advisory as a confirmed product vulnerability or call no-match evidence a guarantee.

## Remediation snapshot, 2 November 2026

The 1 November baseline above and its 115 advisory records, 77 alias groups and 15 distinct packages are retained as historical evidence. The licensing-tool candidate updates Wrangler to 4.156.0, @cloudflare/workers-types to 5.20261023.1 and undici to 7.30.1. The earlier available local verification on Node 26.10.0/npm 11.19.1 passed 647 unit tests and type checking; it did not satisfy the exact-runtime check. A separate 2 November follow-up verified Node v24.21.0 against the official distribution SHA-256 manifest and npm 11.19.0 against registry version metadata and SHA-512 integrity. With these exact versions, isolated `npm ci --ignore-scripts --no-audit --no-fund`, direct TypeScript checking and the 647-test Vitest suite passed. See [verification notes](verification-20261102.md) and the persistent evidence report `artifacts/exact-tool-checks/REPORT.md`. These bounded checks do not certify production dependencies, native installed behaviour, release readiness or runtime clearance.

## Review priorities before any reuse

- **PyJWT 2.13.0:** triage recommends at least 2.15.0 for records with fixed ranges. Fresh options objects mitigate one options-mutation record, which has no fixed version in the data. Other paths have distinct conditions; see the detailed per-advisory notes. Keep that mitigation and separately review recursive header handling and transport bounds.
- **certifi 2026.6.17:** HTTPS trust use is conditionally reachable through requests; the structured fixed range begins at 2026.10.18 and the advisory recommends 2026.10.19 because unaffected roots were restored there.
- **urllib3 2.7.0:** streaming paths make some parser cases conditional; the reviewed fixed boundary is 2.8.0. Proxy environment configuration was not inspected.
- **python-multipart 0.0.27:** dashboard upload parsing reaches multipart handling, with impact depending on the relevant parser/intermediary conditions. Triage records 0.0.31 as covering the listed records; sibling portal locks already use 0.0.32.
- **System.Security.Cryptography.Pkcs 8.0.1:** SignedCms.CheckSignature is reachable after earlier MSIX trust checks and bounded extraction; minimum known fixed is 8.0.2. Preserve the existing trust and size guards.
- **golang.org/x/net v0.57.0:** the vendor-sync HTML parser path is conditional; triage records v0.62.0 for all listed x/net records. go.mod declares Go 1.26.6, while advisory records include standard-library fixed branches 1.26.9 and 1.27.2. The actual build toolchain is unknown; updating x/net does not establish a Go standard-library fix.

Other rows include test-only tooling, output-only workbook generation, unused affected API families, or indirect paths that remain unresolved. In particular, do not infer that all listed package advisories affect the product. Do not upgrade, install or run dependency checks as part of this reading guide.

## Advisory references

Each canonical advisory identifier and its source URL, affected range and evidence are retained in [dependency-review.json](dependency-review.json). OSV records can be opened at `https://osv.dev/vulnerability/ID`, replacing `ID` with the identifier; .NET records are linked to their source announcements in the JSON. The static review did not read every advisory body line by line and several long bodies were truncated in the source triage process.
