# Security

This is archived code from a prototype I stopped developing on 1 November 2026. It is not maintained, so please do not install its helpers, run updates with it or deploy its services.

Before publishing, the code and its history were scanned for secrets. The only matches are test fixtures, and the signing keys in the repository are test keys that carry no real trust.

The parts most worth a security minded read are the catalogue verification, the artifact checks and the transaction journal, which are described in the [case study](docs/portfolio-case-study.md).

If you spot something, I would genuinely like to hear about it; please open an issue without including any credentials or personal data.
